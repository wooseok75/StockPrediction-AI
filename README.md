# Stock Predictor AI Project

## 1. 프로젝트 개요
주가 데이터(5분봉)와 시장의 수급 에너지를 분석하여 상승/하락 확률을 예측하고, 1D-CNN + LSTM 하이브리드 모델로 수익을 창출하는 프로젝트입니다.

## 2. 주요 기능
- KODEX 200 ETF 데이터 수집 및 전처리
- CNN-LSTM 기반 시계열 예측 모델 학습
- 익절/손절 로직을 통한 자동 매매 시스템 구축

## 3. 개발 목표
- 시장 변동성을 활용한 단타 수익 모델 검증
- 실전 매매 최적화

## 4. 입력 데이터
- 총 17개의 Feature를 활용하여 차트의 형태와 흐름을 학습합니다.
- **기본 가격 데이터 (5개)**: 시가(Open), 고가(High), 저가(Low), 종가(Close), 거래량(Volume)
- **기술적 지표 (추가 예정)**: MA, RSI, MACD, 볼린저 밴드 등 추세 및 과매수/과매도 지표
- **수급 및 외부 시장 지표 (추가 예정)**: 외국인/기관 당일 누적 수급, KOSPI 200 야간 선물 지수 변동성 등

## 5. 학습 데이터 전략: 장세별 균형 및 시퀀스 학습
특정 시장 환경에만 최적화되어 실전에서 무너지는 '시간적 과적합(Temporal Overfitting)'을 방지하기 위해 이형(異形) 장세 데이터를 결합합니다.

* **데이터셋 구성**
    * **BULL 모드**: 2025-05-27 ~ 2026-05-27
    * **BEAR 모드**: 2022-01-01 ~ 2022-12-31
* **'카드 섞기' 학습 기법**
    * **시퀀스 분리 생성**: 장세별(BULL/BEAR)로 30개 봉 단위의 학습용 시퀀스를 각각 독립적으로 생성하여, 데이터 경계면에서 발생하는 시차 왜곡 오류를 원천 차단합니다.
    * **무작위 셔플(Shuffle)**: 생성된 두 카드팩을 통합한 뒤 무작위로 뒤섞어, AI가 특정 연도나 장세에 편향되지 않고 순수한 차트 패턴과 인과관계만 학습하도록 유도합니다.



## 6. 현재 프로젝트 상태 및 당면 과제
현재 데이터 수집 파이프라인의 뼈대는 완성되었으나, 증권사 API의 기술적 제약으로 인해 일부 과거 데이터 확보에 난항을 겪고 있습니다.

* **당면 이슈: 과거 분봉 데이터 접근 제한**
    * **현상**: 한국투자증권 Open API를 통한 2022년도 BEAR 모드 데이터 호출 시, `single positional indexer is out-of-bounds` 에러 및 데이터 공백 확인.
    * **원인**: 한투 API의 인트라데이 데이터 제공 범위가 최근 수개월로 제한되어 있어, 4년 전의 과거 분봉 조회 불가.
* **해결 및 우회 로드맵**
    * **대안 A (API 확장)**: 대신증권 크레온(CYBOS Plus) API의 과거 분봉 조회 기능을 활용하여 데이터셋 보완.
    * **대안 B (데이터 확보)**: KRX 정보데이터시스템을 통한 2022년 KODEX 200 주식일별분봉 데이터셋 정식 구매 및 이식.
